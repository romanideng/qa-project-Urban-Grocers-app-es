# Proyecto Urban Grocers 

## Descripción

Se realizó la automatización de pruebas para el campo "name" en la creación de kits dentro de un usuario, no una tarjeta.
En el proyecto se automatizaron 5 pruebas positivas y 4 pruebas negativas. Se cubren todos los métodos GET, POST, PUT, y DELETE. Hallando bugs en la creación de kits con el campo "name" diferente a los requisitos deseados.
